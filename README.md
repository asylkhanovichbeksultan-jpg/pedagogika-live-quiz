# QUIZ ARENA — Педагогика Live

Қазақша **Kahoot стиліндегі тікелей онлайн ойын**. Жүргізуші бөлме ашады, қатысушылар QR немесе PIN арқылы атымен кіреді. Сұрақтар бір уақытта көрсетіледі, дұрыс әрі жылдам жауап көбірек ұпай жинайды, рейтинг және жеңімпаздар подиумы бар.

**15 сұрақ:** 10 оңай (22 сек), 3 орташа (28 сек), 2 қиын (35 сек). Тақырыптар: оқытудағы диагностика, үлгерім және бақылау түрлері, дидактика, педагогикалық технологиялар, отандық оқыту теориялары. Сұрақтар пайдаланушы ұсынған 8-апта дәрісі мен педагогика силлабусының көрінетін бөлімдерінен құрастырылған.

## Интернетке бір басумен жариялау

[**🚀 Deploy to Render — сайтты жариялау**](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fasylkhanovichbeksultan-jpg%2Fpedagogika-live-quiz)

Render аккаунтына кіріп, тегін Web Service жасауға рұқсат беріңіз. Жариялау сәтті аяқталғанда Render сайтқа `https://...onrender.com` адресін береді.

Жүргізуші: `https://...onrender.com/host`.
Қатысушы: жүргізуші экранындағы QR код немесе PIN.

## Render-ді қолмен баптау

- **New → Web Service → Git Provider**: `asylkhanovichbeksultan-jpg/pedagogika-live-quiz`
- **Branch:** `main`
- **Language:** `Node`
- **Build Command:** `npm install`
- **Start Command:** `npm start`
- **Instance:** `Free`

Бұл **Web Service**, Static Site емес: сұрақ уақытын сервер бақылайды, әр қатысушының ұпайы серверде есептеледі.

## Компьютерде тексеру

Node.js 18+ орнатып, `npm test` (3 автоматтандырылған тест) және `npm start` орындаңыз. `http://localhost:3000/host` мекенжайын ашыңыз.

## Ескертпе

Render тегін қызметі 15 минут әрекетсіздіктен кейін ұйқыға кетуі мүмкін; қайта оянған немесе қайта іске қосылған кезде жадтағы ойын бөлмелері жоғалады. Сессия кезінде браузерді жауып қоймаңыз. QR суреті үшін үшінші тараптың QR API-і қолданылады; ол ашылмаса, URL мен PIN арқылы қосылуға болады.
